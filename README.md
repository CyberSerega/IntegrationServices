<h3>Сценарии использования:</h3>
<h4> UC1_2: Найти и выбрать автомойку</h4>
	<p>Участники: пользователь приложения</p>
	<p>Предусловия: пользователь зашел в приложение</p>
	<p>Условия для запуска сценария: пользователь приложения нажимает кнопку "Найти мойку"</p>
	<p>Признак успешности: Пользователь видит список моек на экране и выбирает одну</p>
	<p><i>Базовый сценарий:</i></p>
	<ol>
		<li>Система предлагает использовать геолокацию пользователя</li>
		<li>Если пользователь согласился дать геолокацию:
			<ul>
				<li>Система ищет ближайшие к нему автомойки</li>
				<li>Система возвращает карту или список ближайших автомоек</li>
			</ul>
		 </li>
		 <li>Если пользователь отказался:
			<ul>
				<li>Система выводит список всех автомоек либо показывает карту.</li>
			</ul>
		 </li>
		<li>Пользователь выбирает автомойку из списка или указывает ее на карте.</li>
	</ol>

<h4> UC3: Выбрать дату и время</h4>
	<p><i>Участники</i>: пользователь приложения</p>
	<p><i>Предусловия</i>: пользователь выбрал автомойку из списка</p>
	<p><i>Условия для запуска сценария</i>: пользователь приложения нажимает кнопку "Выбрать время"</p>
	<p><i>Признак успешности</i>: Пользователь видит список свободных слотов на запись</p>
	<p><i>Базовый сценарий:</i></p>
	<ol>
		<li>Система находит указанную мойку в БД и выводит даты, на которые можно записаться</li>
		<li>Пользователь выбирает определенную дату из списка</li>
	</ol>

<h4> UC4: Выбрать услугу</h4>
	<p><i>Участники</i>: пользователь приложения</p>
	<p><i>Предусловия</i>: пользователь выбрал автомойку из списка, выбрал дату и время</p>
	<p><i>Условия для запуска сценария</i>: пользователь приложения нажал кнопку "Записаться"</p>
	<p><i>Признак успешности</i>: Пользователь видит список услуг на данной мойке, их стоимость и выбирает.</p>
	<p><i>Базовый сценарий:</i></p>
	<ol>
		<li>Система находит указанную мойку в БД и выводит услуги, которые она предоставляет</li>
		<li>Пользователь выбирает услугу.</li>
		<li>Пользователь оставляет имя, номер авто, номер телефона для связи</li>
	</ol>

<h4> UC5: Отменить услугу</h4>
	<p><i>Участники</i>: пользователь приложения</p>
	<p><i>Предусловия</i>: пользователь выбрал автомойку из списка, выбрал дату и время, выбрал услугу, записался, вышел из приложения. Вернулся через некоторое время.</p>
	<p><i>Условия для запуска сценария</i>: пользователь приложения нажал кнопку "Отменить запись"</p>
	<p><i>Признак успешности</i>: Запись пользователя отменяется.</p>
	<p><i>Базовый сценарий:</i></p>
	<ol>
		<li>Пользователь вводит номер телефона</li>
		<li>Система находит записи пользователя на будущие даты (с текущей) </li>
		<li>Пользователь выбирает запись и нажимает кнопку "Отменить"</li>
		<li>Ответ системы: "Запись отменена."</li>
	</ol>

<h4> UC6: Оплатить</h4>
	<p><i>Участники</i>: пользователь приложения</p>
	<p><i>Предусловия</i>: пользователь выбрал автомойку из списка, выбрал дату и время, выбрал услугу, записался</p>
	<p><i>Условия для запуска сценария</i>: пользователь нажал кнопку "Оплатить заранее"</p>
	<p><i>Признак успешности</i>: оплата пользователя прошла успешно</p>
	<p><i>Базовый сценарий 1 (пользователь только что записался):</i></p>
	<ol>
		<li>Пользователю выводится стоимость всех услуг</li>	
		<li>Пользователь способ оплаты, оплачивает</li>
		<li>Ответ системы: "Оплата прошла успешна."</li>
	</ol>			
	<p><i>Базовый сценарий: (пользователь записался, но решил оплатить потом)</i></p>
	<ol>
		<li>Пользователь вводит номер телефона</li>
		<li>Система находит записи пользователя на будущие даты (с текущей) </li>
		<li>Пользователь выбирает запись и нажимает кнопку "Оплатить заранее"</li>
		<li>Пользователю выводится стоимость всех услуг</li>	
		<li>Пользователь способ оплаты, оплачивает</li>
		<li>Ответ системы: "Оплата прошла успешна."</li>
	</ol>

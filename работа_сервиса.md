<p>Редактор PlainText</p>

<h3>Подготовка к записи на мойку (мойка, дата, время, услуга) </h3>

```uml

@startuml

actor "Клиент" as client
participant "Веб-сервис" as api
participant "База данных" as db

client -> api: Получить список моек
api -> db: Выгрузить список  моек
db -> db
db -> api: Список моек
api -> client: Список моек
client -> client: Выбирает одну


client -> api: Получить список свободных слотов на мойке
api -> db: Выгрузить список свободных слотов
db -> db
api <- db: Список свободных слотов
api -> client: Список свободных слотов
client -> client: выбирает один слот

client -> api: Получить список услуг
api -> db: Выгрузить список услуг
db -> db
api <- db: Список услуг
api -> client: Список услуг
client -> client: выбирает услугу

@enduml

```

<h3>Механизм записи на автомойку (ввод данных, подтверждение телефона + оплата)</h3>

```uml

@startuml

actor "Платежная система" as ps
actor "Клиент" as client
participant "Веб-сервис" as api
participant "База данных" as db
participant "Сервис оплаты" as ps

client -> client: Выбрал мойку
client -> client: Выбрал дату и время
client -> client: Выбрал услугу
client -> api: Записаться на мойку
api -> client: Запрашивает номер телефона и номер авто
client -> api: Номер телефона + номер авто
api -> client: Запрос на подтверждение
client -> api: Подтверждает номер телефона (через SMS)
api -> api: Подтверждение
client <- api: Цена заказа, предложение оплатить
client --> api: Оплата
api --> ps: Оплата
api <-- ps: Оплата
client <-- api: Подтверждение оплаты
api -> db: Сохранить запись
db -> db: Сохранение
db -> api: Успешное сохранение
api -> client: Вы успешно записались на автомойку!


@enduml

```




<h3>Вариант отмены записи на мойку</h3>

```uml

@startuml

actor "Клиент" as client
participant "Веб-сервис" as api
participant "База данных" as db

client -> api: Отменить запись
api -> client: Запрос номера телефона
client -> api: Номер телефона
api -> db: Выгрузить записи пользователя на ближайшие даты
db -> db
db -> api: Записи пользователя на ближайшие даты
api -> client: Записи пользователя
client -> api: Выбор одной записи
api -> db: Удалить запись из БД
db -> db
db -> api: Запись удалена успешно
api -> client: Ваша запись успешно отменена

@enduml

```

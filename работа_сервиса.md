<h2>Код диаграмм работы сервиса</h2>
<p>Редактор PlainText</p>
<h3>Сервис для записи на мойку</h3>

```uml

@startuml

actor "Платежная система" as ps
actor "Клиент" as client
participant "Веб-сервис" as api
participant "База данных" as db
participant "Сервис погоды" as ws
participant "Сервис оплаты" as ps

client -> api: Получить список моек
api -> db: Выгрузить список  моек
db -> db
db -> api: Список моек
api -> client: Список моек


client -> api: Получить список свободных слотов
api -> db: Выгрузить список свободных слотов
db -> db
api <- db: Список свободных слотов
api -> client: Список свободных слотов

client -> api: Получить список услуг
api -> db: Выгрузить список услуг
db -> db
api <- db: Список услуг
api -> client: Список услуг

client -> api: Заказ + номер телефона, номер авто
api -> ws: Проверить погоду на дату записи
ws -> ws
api <- ws: Прогноз погоды
api <- api: Формирует скидку
client <- api: Цена заказа + скидка
client -> api: Оплата
api -> ps: Оплата
api <-- ps: Оплата
client <-- api: Подтверждение оплаты
@enduml

```

<h3>Вариант отмены записи на мойку</h3>

```uml

@startuml

actor "Клиент" as client
participant "Веб-сервис" as api
participant "База данных" as db

client -> api: Отменить запись
api -> client: Запрос номера телефона
client -> api: Номер телефона
api -> db: Выгрузить записи пользователя на ближайшие даты
db -> db
db -> api: Записи пользователя на ближайшие даты
api -> client: Записи пользователя
client -> api: Выбор одной записи
api -> db: Удалить запись из БД
db -> db
db -> api: Запись удалена успешно
api -> client: Ваша запись успешно отменена

@enduml

```
